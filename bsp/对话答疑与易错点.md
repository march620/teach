# 对话答疑与易错点（BSP 课课堂实录摘要）

本文整理自一次以 `OK1126B-linux-source` 为教材的 BSP 教学对话，收录学员常见误解与纠正，便于复习。

---

## 1. 软链接 ≠ 脚本依赖

**误解：** `Makefile`「链接了」`build.sh`、`configs`、`output`…

**纠正：**

- 软链接：`Makefile` → `device/rockchip/common/Makefile` 等（`ls -l` 看 `->`）。
- `configs` / `output` / `parameter.txt` 是编译过程读写的对象，不是软链接。

```bash
readlink -f Makefile build.sh rkflash.sh
```

---

## 2. `parameter.txt` 里的 boot

**误解：** boot 是「启动地址」；文件里写了 RAM/FLASH 容量。

**纠正：**

- `boot` 是放 **内核 FIT（boot.img）** 的分区。
- `CMDLINE` 是分区布局；一般不直接写整机 RAM/FLASH 容量。

---

## 3. FlashData / FlashBoot

**误解：** Flash 里放数据的分区 / 放启动程序的分区。

**纠正（RKBOOT ini）：**

- `FlashData` = **DDR 初始化** bin  
- `FlashBoot` = **SPL**  
- 再合成 `*_spl_loader_*.bin`

真正的用户分区名在 `parameter.txt`：`uboot` / `boot` / `rootfs`…

---

## 4. PARTUUID

**误解：**（初期）不知道为何要对齐。

**纠正：**

内核用 `root=PARTUUID=...` 找根分区；该 UUID 必须与 `parameter.txt` 里 `uuid:rootfs=...` 一致，否则找不到 `/`。

---

## 5. 编译目标与分区名

| 说法 | 对不对 |
|------|--------|
| 改 DTS → `make kernel` 再打包/刷 boot | ✅ |
| 目标写成 `make update` | ❌ 应为 `make updateimg` 或 `make firmware` |
| `boot.img` 进「kernel 分区」 | ❌ 分区名是 **`boot`** |
| 整包 `update.img` vs 单分区 img | ✅ 整包全更；单 img 只更对应分区 |

只改 DTS → 只刷 **boot**（先 `make kernel`）。

---

## 6. GPIO 三元组

**误解：** `<&gpio0 RK_PB2 GPIO_ACTIVE_LOW>` =「在 PB0，0 亮 1 灭」。

**纠正：** `gpio0` 控制器 + **PB2** 脚 + **低电平有效**。

---

## 7. `&leds` vs `leds`

**错误：** 顶层写 `&leds { ... }`（本板无 `leds:` 标签时 DTC 失败）。

**正确：** 在 `/ { }` 内写 `leds { ... }` 新建节点。  
`&fiq_debugger` 才是「修改已有节点」。

另：DTS 里不要用中文全角 `；`。

---

## 8. 「编译成功」但没编到 practice

**现象：** `make kernel` 成功，但 `output/defconfig` 仍指向 S；没有 `OK1126B-practice-linux.dtb`。

**原因：**

1. 未先 `make OK1126B_PRACTICE_buildroot_defconfig`，或  
2. 看错了指示器：

- **以 `output/.config` 为准**（应含 `RK_KERNEL_DTS_NAME="OK1126B-practice-linux"`）
- `output/defconfig` 软链可能仍指向 S；它由 `./build.sh *_defconfig` 的 `switch_defconfig` 更新，纯 `make *_defconfig` 主要写 `.config`

`OK1126B_PRACTICE_buildroot_defconfig` 文件本身配置是对的（hostname + practice DTS 名）。

## 10. 推荐复习命令清单

```bash
cd /path/to/OK1126B-linux-source

# 选练习板并确认
make OK1126B_PRACTICE_buildroot_defconfig
grep -E 'RK_DEFCONFIG|RK_KERNEL_DTS_NAME|RK_ROOTFS_HOSTNAME' output/.config

# 编内核 / 看产物
make kernel
ls -l kernel-6.1/arch/arm64/boot/dts/rockchip/OK1126B-practice-linux.dtb
ls -l output/firmware/

# 烧录（有板、USB 可用时）
./rkflash.sh boot

# Rootfs overlay 示例路径
ls device/rockchip/common/overlays/rootfs/default/
```
