# 7.4 RKAIQ：相机 ISP / 3A

路径：`external/camera_engine_rkaiq/`  
板级相机 DT：`kernel-6.1/.../OK1126B-S-camera.dtsi`  
文档：`docs/rv1126b/cn/Common/ISP/`、`docs/.../Linux/Camera/`  
主 API：`rkaiq/include/uAPI2/rk_aiq_user_api2_sysctl.h`  
Demo：`rkisp_demo/`

---

## 1. RKAIQ 是什么

**RKAIQ = Rockchip Auto Image Quality**：用户态 **ISP 画质引擎**。

| 能力 | 含义 |
|------|------|
| AE / AWB / AF | 曝光、白平衡、对焦（3A） |
| 其它 | NR、锐化、HDR、AI-ISP… |

**不管音频**（音频是 Rockit AI/AO 等）。

分工：

| 模块 | 职责 |
|------|------|
| **RKAIQ** | 把 Sensor 图调好看（亮、色、噪） |
| **Rockit VI** | 从 ISP 输出把视频流接进多媒体管道 |

---

## 2. 正确顺序（易错）

**不是** `VI → RKAIQ → VO`。

```text
Sensor → ISP硬件 + RKAIQ(控画质) → YUV
              ↓
         Rockit VI（取流）
              ↓
         VO / VENC / NPU …
```

偏色、全绿、严重过曝：优先查 **AIQ + IQ**，不是先查 `mpi_enc_test`。

---

## 3. 软件启动节奏

```text
1. 找到 sensor 的 media entity 名（sns_ent_name）
2. rk_aiq_uapi2_sysctl_init(sns, iqpath, …)
3. prepare → start
4. 再开 VI / 取流
5. stop → deinit
```

| 参数 | 含义 |
|------|------|
| **sns_ent_name** | 系统里这颗相机的 **media 实体名**（不是「光学参数表」） |
| **iqpath** | 该模组 IQ 文件目录（如 `/oem/etc/iqfiles`） |

换模组/镜头常需换 IQ。

---

## 4. 与 DTS

`OK1126B-S-camera.dtsi`：上电脚、I2C、CSI lane、compatible（如 ov13850）。

| 层 | 管什么 |
|----|--------|
| DTS + sensor 驱动 | 硬件出图节点 |
| RKAIQ + IQ | 效果参数 |
| Rockit VI | 取 YUV 进管道 |

---

## 课后要点

1. AIQ 在 VI **之前/并行控 ISP**，不是 VI 后面再「优化一遍流」。  
2. 画质问题先 AIQ；编码问题再 MPP/VENC。
