# 6.1 交叉编译与 `file` 命令

接第 6 课：把 C 程序编成板子能跑的二进制，再放进 overlay。

**示例工程（SDK 内）：**

```text
app/practice_hello/hello.c
app/practice_hello/Makefile
→ install 到
device/rockchip/common/overlays/rootfs/default/usr/bin/practice_hello
→ 板上 /usr/bin/practice_hello
```

---

## 1. 为什么要交叉编译

| 编译器 | 产物跑在哪 |
|--------|------------|
| 主机 `gcc` / `cc` | PC（x86_64） |
| `aarch64-none-linux-gnu-gcc` | 板子（ARM64 Linux 用户态） |

本 SDK 用户态工具链示例：

```text
prebuilts/gcc/linux-x86/aarch64/gcc-arm-10.3-2021.07-x86_64-aarch64-none-linux-gnu/bin/
  aarch64-none-linux-gnu-gcc
```

| 工具链后缀 | 用途 |
|------------|------|
| **`aarch64-none-linux-gnu`** | Linux 用户态程序（本课） |
| `aarch64-none-elf` | 裸机，**不要**拿来编 Linux App |

---

## 2. `file` 命令干什么

`file` 识别文件类型/架构，编完必看一眼：

```bash
file practice_hello
# 正确应含: ARM aarch64
# 错误若是: x86-64 → 用了主机 gcc，板上跑不了
```

| 关键词 | 含义 |
|--------|------|
| `ARM aarch64` | 给板子 |
| `x86-64` | 给 PC |
| `POSIX shell script` | 脚本 |
| `C source` | 源码文本 |

---

## 3. 推荐 Makefile 写法

环境里若已有 `CC=cc`，写成 `CC ?= 交叉gcc` **不会生效**，会默默编成 x86。  
应用 `CC :=` 强制指定：

```makefile
SDK_ROOT := $(abspath ../..)
CROSS_GCC := $(SDK_ROOT)/prebuilts/gcc/linux-x86/aarch64/gcc-arm-10.3-2021.07-x86_64-aarch64-none-linux-gnu/bin/aarch64-none-linux-gnu-gcc
CC := $(CROSS_GCC)
CFLAGS := -O2 -Wall
TARGET := practice_hello
OVERLAY_BIN := $(SDK_ROOT)/device/rockchip/common/overlays/rootfs/default/usr/bin/$(TARGET)

all: $(TARGET)
$(TARGET): hello.c
	$(CC) $(CFLAGS) -o $@ $<

install: $(TARGET)
	mkdir -p $(dir $(OVERLAY_BIN))
	cp -f $(TARGET) $(OVERLAY_BIN)
	chmod +x $(OVERLAY_BIN)
	file $(OVERLAY_BIN)

clean:
	rm -f $(TARGET)
```

操作：

```bash
cd /path/to/OK1126B-linux-source/app/practice_hello
make clean install
file ../../device/rockchip/common/overlays/rootfs/default/usr/bin/practice_hello
```

---

## 4. 进板子还要 `make rootfs`

overlay 目录里即使已是 aarch64，也只在**主机 SDK**里：

```text
make rootfs          # 打进 rootfs.img
./rkflash.sh rootfs  # 刷 rootfs 分区（有板时）
# 板上: practice_hello
```

`make kernel` **不会**带上用户程序。

---

## 课后要点

1. Linux 用户态用 **`aarch64-none-linux-gnu`**。  
2. 编完用 **`file`** 确认 aarch64。  
3. 进系统：`make rootfs` + 刷 **rootfs**。
