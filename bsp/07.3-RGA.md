# 7.3 RGA：2D 图像加速

路径：`external/linux-rga/`  
文档：`docs/rv1126b/cn/Common/RGA/`  
内核：`kernel-6.1/drivers/video/rockchip/rga*` / `rga2*`  
推荐 API：`im2d_api/`（`im2d.h` / `im2d.hpp`）

---

## 1. RGA 是什么

**RGA = Raster Graphic Acceleration**：2D 硬件，做「改图」，**不做** H.264 编码。

| 操作 | API | sample |
|------|-----|--------|
| 缩放 | `imresize` | `samples/resize_demo` |
| 裁剪 | `imcrop` | `crop_demo` |
| 旋转 | `imrotate` | `transform_demo` |
| 格式转换 | `imcvtcolor` | `cvtcolor_demo` |
| 拷贝 / 混合 | `imcopy` / `imblend` | `copy_demo` / `alpha_demo` |

MPP 管编解码；RGA 管尺寸/格式/方向变换。

---

## 2. 在链路中的位置

```text
VI 出 YUV →（可选）RGA → VENC / NPU / 显示
```

Rockit 的 VPSS/VGS/TDE 内部常会用到同类 2D 能力；也可直接调 librga。

---

## 3. im2d 四步（resize demo）

```text
1. 准备 src_buf / dst_buf（像素内存）
2. importbuffer_*：把内存登记给 RGA，得到 handle（src、dst 各一次）
3. wrapbuffer_handle：给 handle 贴宽高/格式 → rga_buffer_t（不拷贝像素）
4. imcheck → imresize(src, dst)：硬件执行缩放
5. releasebuffer
```

**易错：**

- `wrapbuffer` **不是**复制图片  
- `imresize` 是**动作**，不是「输出缓存」  
- 输出像素在 `dst_buf` / `dst_img` 对应的那块内存里  

resize demo 常见分辨率：源 **1280×720** → 目标 **1920×1080**  
（`samples/resize_demo/src/rga_resize_demo.cpp`）

---

## 4. 怎么选

| 做法 | 适合 |
|------|------|
| RGA | 单次缩放、转格式、旋转 |
| Rockit VPSS | 已在 MPI 管道里多路 Bind |
| CPU | 调试；量产通常不如 RGA |

喂 NPU 前常用 RGA 转到模型输入尺寸/格式。
