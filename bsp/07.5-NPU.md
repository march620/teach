# 7.5 NPU：Toolkit2 → RKNPU2

RV1126B 使用 **RKNPU2** 栈（勿与旧 rknn-toolkit1 混用）。

| 目录 | 跑在哪 | 干什么 |
|------|--------|--------|
| `external/rknn-toolkit2/` | **PC** | 转换/量化 → 产出 `.rknn` |
| `external/rknpu2/` | **板子** | Runtime + examples，消费 `.rknn` |
| `external/rknn-llm/` | PC+板 | 大模型（选学） |
| `docs/.../Common/NPU/` | 文档 | |

---

## 1. 流程

```text
ONNX / PyTorch / TFLite …
        ↓  PC: RKNN-Toolkit2
     model.rknn（针对 RV1126B）
        ↓  拷到板
     rknn_init → inputs_set → run → outputs_get
        ↓
     检测/分类结果 …
```

与相机：

```text
Sensor → RKAIQ → VI →（常加 RGA 缩放到模型输入）
                      → RKNPU2
                      → 业务
         同时可 → VENC 推流
```

---

## 2. PC：`rknn-toolkit2`

`external/rknn-toolkit2/rknn-toolkit2/`  
例子：`examples/onnx`、`pytorch`、`tflite`…  
板上 Python：`rknn-toolkit-lite2`。

---

## 3. 板：`rknpu2` Runtime

```text
external/rknpu2/
├── runtime/Linux/librknn_api/   ← .so + include/rknn_api.h
└── examples/                    ← api_demo、yolov5、mobilenet…
```

**C API 顺序：**

```text
rknn_init
rknn_query          // 常用：查输入输出 shape
rknn_inputs_set
rknn_run
rknn_outputs_get
rknn_outputs_release
rknn_destroy
```

头文件：`runtime/Linux/librknn_api/include/rknn_api.h`

---

## 4. 分工

| 组件 | 角色 |
|------|------|
| VI / RKAIQ | 出图 |
| **RGA** | 缩放到模型尺寸、转格式（不是 MPP） |
| **RKNPU2** | 神经网络推理 |
| MPP/VENC | 视频编码 |

1080p YUV 喂 640×640 RGB YOLO：中间通常插 **RGA**（或 VPSS），因为这是 2D 变换，不是编解码。

---

## 课后要点

1. Toolkit2@PC 产出 `.rknn`；Runtime@板 加载推理。  
2. 板端四步：`inputs_set` → `run` → `outputs_get`（前后加 init/destroy）。  
3. 改分辨率/格式用 RGA，不用 MPP。
