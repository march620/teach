## 1. `external/` 分类

### A. 多媒体主链路（IPC/相机优先）

| 目录 | 是什么 | 在链路上的位置 |
|------|--------|----------------|
| **camera_engine_rkaiq** | ISP / 3A（图像质量） | Sensor → **ISP** → 干净 YUV |
| **rockit** | 多媒体中间件（MPI/TGI） | VI / VPSS / VENC / VO… 拼流水线 |
| **mpp** | 编解码底层库 | 硬件 VPU 做 H.264/H.265 等 |
| **linux-rga** | 2D 图形加速 | 缩放、旋转、格式转换、混合 |
| **gstreamer-rockchip** | GStreamer 插件 | Gst 管道走 Rockchip 加速 |
| **avs** | 多目拼接/融合 | 双目/多路 IPC |
| **iva** | 智能视频分析 | 检测/分析类能力 |
| **common_algorithm** | 通用算法库 | 被上层媒体/AI 复用 |
| **samples** | 媒体示例 | 跟着跑通 API |

相关应用（不在 `external/` 根下）：`app/rkipc`、`app/rkadk`。

### B. NPU / 大模型

| 目录 | 是什么 |
|------|--------|
| **rknpu2** | 板端 NPU 运行时（跑 RKNN 模型） |
| **rknn-toolkit2** | PC 侧：模型转换/量化 |
| **rknn-llm** | 大模型部署栈 |

### C. 周边

| 目录 | 是什么 |
|------|--------|
| **alsa-config** | ALSA 声卡配置 |
| **rkwifibt** / **rkwifibt-app** | WiFi/BT |
| **minilogger** / **rktoolkit** / **rkupdate** / **recovery** | 日志、工具、升级、恢复 |
| **rockchip-test** / **security** / **ipc_drv_ko** | 压测、安全、IPC 内核模块 |

## 2. 典型数据流

```text
Camera Sensor
    → RKAIQ (ISP/3A)          [camera_engine_rkaiq]
    → Rockit VI / VPSS        [rockit]
    → RGA（可选缩放旋转）      [linux-rga]
    → Rockit VENC 或 直接 MPP  [rockit / mpp]
    → 码流 / 文件 / 网络

旁路：YUV/RGB → RKNPU2 推理   [rknpu2]
PC 上：模型 → RKNN            [rknn-toolkit2]
```

记忆：

- **RKAIQ**：把图调好看  
- **Rockit**：拼业务流水线  
- **MPP**：编解码硬件底层  
- **RGA**：2D 搬运/变换  
- **RKNPU2**：AI 加速
