# 第 7 课：平台栈答疑与易错点

课堂对话中的常见误解汇总（7.1–7.5）。

---

## Rockit（7.1）

| 误解 | 纠正 |
|------|------|
| `test_vi_init` 结束后多了「判断」 | 结束后是 **VI 已使能，能出帧** |
| 循环只 usleep 是因为 init 把输入转输出了 | **Bind** 在后台自动送帧；init 只负责采集 |
| 编码把 VO 换成 VDEC / `vdec_bind_vo` | 编码用 **VENC** + `GetStream`；VDEC 是解码 |
| `CreateMB` 等于创建 VI | CreateMB 是申请媒体内存块 |

TGI ≈ 配置固定管道；MPI ≈ API 灵活拼接。IPC 选 MPI。

---

## MPP（7.2）

| 误解 | 纠正 |
|------|------|
| Rockit 的头文件是 `mpp/inc/rk_mpi.h` | 那是 **MPP** 的 MPI；Rockit 是 `rk_mpi_vi.h` 等 |
| 编码送 Packet | 编码送 **Frame**，出 **Packet** |

---

## RGA（7.3）

| 误解 | 纠正 |
|------|------|
| wrapbuffer = 复制图片 | 只是给 handle **贴元数据**，不拷像素 |
| imresize = 输出缓存 | imresize 是 **缩放动作**；像素在 dst 缓冲里 |

四步：import 登记 → wrap 描述 → im* 干活 → release。

---

## RKAIQ（7.4）

| 误解 | 纠正 |
|------|------|
| AIQ 也优化音频 | **不管音频**，只管相机 ISP/3A |
| 流是 `VI → RKAIQ → VO` | 应是 **Sensor/ISP+AIQ → VI → VO/VENC** |
| sns_ent_name = 光学参数 | 是 **media 实体名**；iqpath 才是 IQ 目录 |

偏色优先查 AIQ/IQ。

---

## NPU（7.5）

| 误解 | 纠正 |
|------|------|
| 板端直接跑 ONNX | 一般先 **Toolkit2 → .rknn** 再 Runtime |
| 缩放到模型输入用 MPP | 用 **RGA**（或 VPSS），MPP 是编解码 |

---

## 一张总图

```text
Sensor → RKAIQ → VI → RGA? → RKNPU2?
                    ↘ VPSS? → VENC(MPP) → 网络/文件
                    ↘ VO → 屏幕
```
