# 7.2 MPP：编解码底层

路径：`external/mpp/`  
内核：`kernel-6.1/drivers/video/rockchip/mpp/`（含 `mpp_service.c`）  
文档：`docs/rv1126b/cn/Common/MPP/`

---

## 1. 先分清两个「MPI」

| 名字 | 路径 | 干什么 |
|------|------|--------|
| **Rockit MPI** | `rockit/.../rk_mpi_vi.h`、`rk_mpi_venc.h`… | 拼 VI/VPSS/VENC/VO 全流程 |
| **MPP 的 MPI** | `external/mpp/inc/rk_mpi.h` | **只做**硬件编解码 |

Rockit 的 `RK_MPI_VENC_*` 底层往往会再调到 MPP。

---

## 2. MPP 是什么

**MPP = Media Process Platform**：面向 VPU 的用户态库。

```text
YUV Frame ──encode──→ H.264/H.265 Packet
Packet    ──decode──→ Frame
```

```text
App / Rockit VENC
   → MPP（mpp_create / encode_put_frame …）
      → 内核 mpp 驱动（mpp_service + rkvenc/rkvdec…）
         → 硬件
```

---

## 3. 目录

```text
external/mpp/
├── inc/          ← rk_mpi.h、mpp_frame.h、mpp_packet.h
```

---

## 4. 编码最小节奏

```text
mpp_create(&ctx, &mpi)
mpp_init(ctx, MPP_CTX_ENC, 格式)
mpi->control(...)           // 宽高码率等

循环:
  encode_put_frame(ctx, frame)   // 送 Frame
  encode_get_packet(ctx, &pkt)   // 取 Packet
  写文件/送网络

mpp_destroy(ctx)
```

**编码：送进去是 Frame，拿出来是 Packet。**

对照示例（行号以具体树为准，rk3588 的 `mpi_enc_test.c` 一次课堂记录）：

| API | 约略行号（示例） |
|-----|------------------|
| `mpp_create` | ~914 |
| `encode_put_frame` | ~758 |
| `encode_get_packet` | ~768 |

飞凌树路径：`external/mpp/test/mpi_enc_test.c`（行号可能略有差异，以搜索为准）。

---

## 5. 与 Rockit VENC 对照

| Rockit | MPP |
|--------|-----|
| `VENC_CreateChn` | `mpp_create` + `mpp_init(ENC)` |
| Bind / SendFrame | `encode_put_frame` |
| `VENC_GetStream` | `encode_get_packet` |

Rockit 管多路绑定与业务；MPP 管喂硬件、出 NAL。

---

## 课后要点

1. `mpp/inc/rk_mpi.h` 属于 MPP，不是 Rockit 全流程头文件。  
2. 编码 Frame→Packet；解码 Packet→Frame。
