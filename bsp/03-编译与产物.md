# 第 3 课：编译与产物

目标：会选板、会按改动范围增量编译，认识 `output/firmware/`。

---

## 1. 日常流水线

```text
① make OK1126B_S_buildroot_defconfig   # 选板（或 PRACTICE）
② 改代码 / DTS / 配置
③ make kernel / uboot / rootfs ...     # 按改动范围
④ make firmware 或 make updateimg      # 打包
⑤ 烧录 output/firmware/update.img 等
```

根目录 `make` 最终会调到 `build.sh`。`make help` 里较长列表来自 `build.sh make-usage`。

---

## 2. 改什么编什么

| 你改了什么 | 命令 | 产物大致位置 |
|-----------|------|--------------|
| DTS / 内核驱动 | `make kernel` | `kernel-6.1/boot.img`、`.dtb` |
| U-Boot | `make uboot` | `u-boot/uboot.img`、loader |
| Buildroot 用户态 | `make buildroot` / `make rootfs` | `output/buildroot/images/rootfs.ext4` |
| 重新打包 | `make firmware` / `make updateimg` | `output/firmware/update.img` |
| 全量 | `make all` 或 `make` | 全部 |

只改 DTS 时最少：

```bash
make kernel
make updateimg   # 若需要整包；也可只刷 boot.img
```

注意：目标名是 **`updateimg`**，不是 `update`。

---

## 3. `output/firmware/` 对照启动链

| 文件 | 对应阶段 |
|------|----------|
| `MiniLoaderAll.bin` | Loader（DDR+SPL） |
| `uboot.img` | U-Boot |
| `boot.img` | 内核 FIT（Image + dtb）→ **boot 分区** |
| `rootfs.img` | 根文件系统 → **rootfs 分区** |
| `parameter.txt` | 分区表 |
| `update.img` | 整包升级镜像 |

- **`update.img`**：更新整系统（多分区）。
- **单个 `.img`**：只更新对应分区（如只改 DTS → 只刷 `boot`）。

---

## 4. 选板：以谁为准？

`make OK1126B_PRACTICE_buildroot_defconfig` 会写入：

```text
output/.config
```

其中应有：

```text
RK_DEFCONFIG="OK1126B_PRACTICE_buildroot_defconfig"
RK_KERNEL_DTS_NAME="OK1126B-practice-linux"
```

**注意：** `output/defconfig` 软链不一定会随之更新。  
软链是 `./build.sh …_defconfig`（`switch_defconfig`）才会改的。

确认应用哪套配置，请看：

```bash
grep RK_KERNEL_DTS_NAME output/.config
# 不要只看 output/defconfig 软链
```
